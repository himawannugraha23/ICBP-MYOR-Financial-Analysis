# Financial Performance & Competitor Benchmarking
### A Comparative Financial Analysis of PT Indofood CBP Sukses Makmur Tbk (ICBP) and PT Mayora Indah Tbk (MYOR), 2020–2025

## Project Overview

This project analyzes and compares the financial performance of two major Indonesian consumer goods companies, PT Indofood CBP Sukses Makmur Tbk (ICBP) and PT Mayora Indah Tbk (MYOR).

The analysis focuses on revenue performance, profitability, liquidity, solvency, and cash flow to understand each company's financial condition, operational efficiency, and business performance.

## Business Objectives

- Evaluate revenue growth and financial performance.
- Compare profitability between ICBP and MYOR.
- Assess liquidity and financial risk.
- Examine operating cash flow and capital expenditure.
- Develop data-driven business insights and recommendations.

## Tools & Technologies

- SQL: Google BigQuery
- Python: Google Colab, Pandas, NumPy, Matplotlib, Seaborn
- Data Visualization: Power BI
- Data Management: Excel, CSV, GitHub
