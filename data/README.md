# Dataset Documentation

## Main Dataset: Raw Financials

The dataset contains financial statement information for:

- PT Indofood CBP Sukses Makmur Tbk (ICBP)
- PT Mayora Indah Tbk (MYOR)

**Observation period:** 2020–2025

**Expected observations:** 12 company-year records.

## Variables

| Variable | Description |
|---|---|
| company | Company name |
| fiscal_year | Financial reporting year |
| net_sales | Net sales |
| cogs | Cost of goods sold |
| gross_profit | Gross profit |
| operating_profit | Operating profit |
| profit_for_year | Profit for the year |
| total_assets | Total assets |
| total_liabilities | Total liabilities |
| total_equity | Total equity |
| cfo | Cash flow from operating activities |
| capex_ppe | Capital expenditure on property, plant and equipment |

## Data Quality

The dataset is undergoing validation against the original audited annual reports.

Missing values, accounting classification differences, and reconciliation discrepancies must be investigated before final analysis.
